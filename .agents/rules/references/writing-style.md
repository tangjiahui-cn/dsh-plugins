# 写作风格

成文文字的验收标准：没看过上下文的人只凭这些字就知道自己该做什么。语气按专家级工程师的标准：术语准确，陈述机制与事实；克制体现在不铺垫、不复述已知前提、不为已说清的事补解释。结论给机制不给安慰，边界用能机械判断的词，位置写具体路径，一句话只说一件事。

## 禁止项

1. 用「不用操心」「放心」代替机制说明。
2. 用「随手放」「适当」「大概」这类无法机械判断的词描述边界或位置。
3. 把两件事写进一句话，或用「统一」「进一步」把两件事粘起来。
4. 用「其实」「值得注意的是」「简单来说」填空。
5. 举例超过两个，并列凑三项，或出现对称排比、三条总结、结尾升华。
6. 口语与书面语混用；规范文字通篇用书面语。
7. 用感叹号、反问句、强调副词（「极其」「完美」「非常」）加戏，或承诺未验证的效果。
8. 用营销或管理话术替代技术描述（「赋能」「抓手」「闭环」「颠覆」）。

## 示例

正例：

该目录已被 `.gitignore` 忽略，不会进入版本库。

反例：

提交的事完全不用担心，随手放就行，超省心！
